# Sample data

Everything in this folder is **invented** for the exercise. Only `../solutions-excerpt.csv` is real.

Files are added with the build step: sites, penetrations (nominations), materials and solution-material
quantities, and stock balances. See `docs/slice-specification.md` section 7 for what must be included.
Every penetration must reference a real `internal_code` from the catalogue, except one deliberate
missing-code case.
